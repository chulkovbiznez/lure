# Чистые страницы EAGLES (11.11.2026, egClean1): Контакты, Ролики, Обучение, Команда, Канал

Было: старая оранжевая страница + скин в самом конце (`/kontakty-novye-v1.js?v=1` для Контактов,
`/zoloto-v1.js?v=1` для остальных четырёх) + «шторка» ANTIMIG, прятавшая страницу до скина.

Стало:
- стили нового вида в `<head>`, класс (`ktn` или `zl zl-<страница>`) сразу на `<html>`;
- ВСЕ стили страницы перенесены из тела в `<head>` (в том же порядке после нового вида — каскад не меняется),
  иначе до стиля в середине страницы браузер рисовал куски старым видом;
- Контакты: подзаголовок, иконка, «Мои люди», деления касаний, кнопка «Добавить контакт» — в разметке;
  живая часть (цифры, инициалы, фильтры) — сразу после главного скрипта страницы;
- Ролики/Обучение/Команда/Канал: скин встроен в начало `<body>`, иконки ставятся наблюдателем в момент
  появления элементов (до первого кадра), а не через 60 мс;
- Канал: вошедшему сразу не показываются «Войти» и «Зарегистрироваться» (класс ek-logged из head);
- ANTIMIG и подключение скинов убраны. Логика, сервер, данные — без изменений.

Сборка: `python3 build.py СТРАНИЦА живой.html скин.js новый.html` (contacts|roliki|obuchenie|binar|kanal).
Проверка: `node t_pages.js ПАПКА ТЕГ` (старая против новой: текст, иконки, вкладки, клики Контактов —
одинаково), `node rec.js ПАПКА страница папка-кадров` (обновление при замедлении 6×).
Скины в бакете не удалять: нужны старым копиям для отката.
