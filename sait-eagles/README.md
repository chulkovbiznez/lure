# Страницы сайта app.eaglesteam.ru для выкладки

Здесь лежат готовые страницы сайта EAGLES, которые Claude в Chrome забирает по точному коммиту
(`codeload.github.com/.../tar.gz/<коммит>`) и кладёт в бакет `app.eaglesteam.ru`.
Сами страницы и так открыты всем на сайте, секретов в них нет.

- `profile.html` (09.11.2026) — живой профиль от 09.11 + экран загрузки: логотип EAGLES «Зеркало твоего бизнеса»
  по центру и золотая полоска вместо битой картинки и слова EAGLES; тот же логотип в окне ПИН-кода.
  Исходник правки и скрипты: репозиторий eagles-mozg, папка `kod/zagruzka/`.
