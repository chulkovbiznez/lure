# Новая главная EAGLES (задание Chrome 32)

`patch_glav.py СТАРЫЙ НОВЫЙ` вставляет `glav-blok.html` перед последним `</body>` index.html сайта app.eaglesteam.ru.
Старый код страницы не меняется: новый вид главной (карусель 12 продуктов) рисуется поверх, а старые кнопки
регистрации, входа и инструкции остаются и вызываются из новых. Регистрация становится мастером из 3 шагов,
старые поля и проверки переносятся внутрь мастера (запросы к серверу те же).

Метка блока: `<style id="glavV1">`. Откат: вернуть резервную копию index.html.
Исходники: репозиторий-мозг, папка kod/glavnaya (shablon, build_blok.py, reg.css, reg.js).
