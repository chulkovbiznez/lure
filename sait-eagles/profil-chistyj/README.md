# Чистый Профиль EAGLES (11.11.2026, pfnClean1)

Было: старая оранжевая страница profile.html + скин `/profil-novyj-v1.js?v=5`, который после загрузки
перекрашивал и переставлял блоки, + «шторка» ANTIMIG, которая прятала страницу, пока скин не сработал
(отсюда долгий экран загрузки и мелькание старого вида).

Стало: новый золотой вид прямо в странице.
- стили нового вида, кнопок «Мои контакты» и LURE — в `<head>`, класс `pfn` сразу на `<html>`;
- разметка уже новая: золотая пыль, деления касаний, кнопки «Мои контакты» и LURE, веер Карт,
  объёмные фигуры чата и копилки, плашка «Взлетай», заголовки партнёрки и партнёров;
- логотип ставится сразу (картинка EG_PLOGO определена до разметки);
- `pfn-live.js` — только то, что зависит от данных (деления касаний, число партнёров, карта PRO,
  приглашение, игра, видео кнопок);
- убраны: ANTIMIG, скин, старая «Карта EAGLES» в окне (кнопка давно ведёт на /karty.html), три видео-иконки.
- Логика, сервер, ПИН, чат, копилка, пакеты, партнёры — те же скрипты живой страницы.

Сборка: `python3 build.py profile.html profil-novyj-v1.js profile-new.html`
(из живого profile.html md5 a873a08b… и скина md5 931d90db… → 788 493 байт, md5 52fa2b0b…).
Скрипт сам проверяет, что все нужные места есть, иначе пишет «СТОП».

Проверка (Playwright): `node t_prof.js СТАРЫЙ old`, `node t_prof.js НОВЫЙ new` → R-old.json и R-new.json
одинаковые (PRO и FREE, пустые партнёры, чат, копилка, «Мои данные», пакеты, Карты → /karty.html,
игра открывается, ссылки, ПИН-экран, без входа). `node rec_prof.js ФАЙЛ папка` — кадры обновления
при замедлении 6×: старый — ~30 кадров экрана загрузки, новый — логотип и сразу вся страница.
