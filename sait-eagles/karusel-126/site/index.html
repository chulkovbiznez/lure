Как зарегистрироваться

ПО ШАГАМ
1.Пришёл по ссылке-приглашению: наставник уже стоит в форме, ничего вписывать не нужно.
2.Зашёл просто на сайт: впиши ID того, кто тебя пригласил. Он есть у него в Профиле под именем. Без ID пригласителя регистрации нет.
3.Придумай свой ID, впиши имя, фамилию и почту.
4.Контакты: заполни минимум один из четырёх. У каждого есть «?» с подсказкой.
5.Отметь галочку и нажми «Начать бесплатно». На почту придёт код из 6 цифр: впиши его, и ты внутри.
