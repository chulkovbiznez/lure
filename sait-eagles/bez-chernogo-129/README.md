# 129 — без пустого экрана между заставкой приложения и экраном загрузки (26.11.2026)
Видео Андрея (1.3): заставка → ~1,2 с пустой серый экран Chrome → экран загрузки профиля.
Причина: приложение стартовало с главной (index.html, переход в профиль без отрисовки), и профиль рисовал экран загрузки не с первого кадра.
Фикс сайта (profile.html, egZ0 в head после egPre128): вошёл и (приложение или первый заход) — #egpZ виден с первой отрисовки; класс снимается после egBoot127. Не вошёл и ?app=android — сразу на главную.
Фикс приложения 1.4: старт сразу с /profile.html?app=android&v=14, mayLaunchUrl для прогрева, заставка 720×1680.
Сборка: python3 p129.py . (живой профиль 6cd4b66a → d705cdd6). Тест t129p.js: экран загрузки виден на первой проверке (было +300 мс).
Порядок: сначала залить профиль, потом ставить 1.4.
