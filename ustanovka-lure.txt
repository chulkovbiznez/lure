УСТАНОВКА LURE НА СЕРВЕР ai-chat. Шаги для Андрея.

ШАГ 1. Клод в Хроме выполняет ЧАСТЬ 1 задания zadanie-4-lure-dns.txt (запись A lure).

ШАГ 2. Ключ движка для LURE.
Открой https://ai.eaglesteam.ru → войди админом → «Токены» → «Добавить токен».
Имя: LURE. Срок: никогда. Квота: безлимит. Группа: default. Сохрани.
Нажми «Копировать» у этого токена. Ключ никому не отправляй, он понадобится в шаге 5.

ШАГ 3. Сертификат для lure (как делали для ai).
В PowerShell:
  ssh -i $HOME\.ssh\ai-chat-key andrey@81.26.180.206
Потом:
  sudo -i
  /root/.acme.sh/acme.sh --issue --dns -d lure.eaglesteam.ru --keylength ec-256 --yes-I-know-dns-manual-mode-enough-go-ahead-please
На экране будет Domain: '_acme-challenge.lure.eaglesteam.ru' и TXT value: '…'.
Отправь это значение Клоду в Хроме (ЧАСТЬ 2 задания). Подожди 5 минут после его ответа.

ШАГ 4. Получить сертификат (одна строка, в том же окне):
  /root/.acme.sh/acme.sh --renew -d lure.eaglesteam.ru --ecc --yes-I-know-dns-manual-mode-enough-go-ahead-please && mkdir -p /opt/ai-chat/certs/lure && /root/.acme.sh/acme.sh --install-cert -d lure.eaglesteam.ru --ecc --key-file /opt/ai-chat/certs/lure/key.pem --fullchain-file /opt/ai-chat/certs/lure/fullchain.pem --reloadcmd "cd /opt/ai-chat && docker compose restart caddy"

ШАГ 5. Поставить LURE (адрес репозитория пришлю):
  cd /root && curl -fsSL АДРЕС_СКРИПТА -o install-lure.sh && bash install-lure.sh АДРЕС_РЕПОЗИТОРИЯ
Скрипт попросит ключ из шага 2: вставь (правой кнопкой мыши) и нажми Enter. Символы не видны, так и должно быть.
В конце будет «ГОТОВО». Открой https://lure.eaglesteam.ru, войди своим ID 11111.

ШАГ 6. Проверка цены.
В LURE задай один вопрос. Под ответом будет цена, например 2,10 ₽.
В https://ai.eaglesteam.ru → «Журнал» у этого же запроса будет списание в $. Умножь на 100: должно совпасть с ценой в LURE.
Пришли мне обе цифры.
