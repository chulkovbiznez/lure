# EYE — видеозвонки EAGLES

- `eye_signal.py` — сервер-соединитель (WebSocket, wss://eye.eaglesteam.ru/ws). Видео через него не идёт.
- `eye.js` — экран звонка для сайта EAGLES (кнопка в «Сообщениях», входящий звонок, разговор).
Секретов в коде нет. Сервер ставится cloud-init'ом (см. мозг проекта, задание 52).
