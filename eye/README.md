# EYE — видеозвонки EAGLES

- `eye_signal.py` — сервер-соединитель (WebSocket, wss://eye.eaglesteam.ru/ws). Видео через него не идёт.
  v2 (16.11.2026): право звонить спрашивает у сервера сайта действием `eye_check` (только взаимные друзья, без блокировки).
- `eye.js` — экран звонка и «друзья» для сайта EAGLES (v2). Лежит в бакете сайта как `/eye.js`, страницы подключают
  `<script src="/eye.js?v=2" defer></script>`. Кнопки «В друзья» / «Принять» / звонок в «Сообщениях», блок «Друзья · EYE»,
  карточка «X хочет дружить» на других страницах, входящий звонок на любой странице.
- `eye-friends-server.js` — добавка в конец server.js функции eagles-server: друзья (fr_list, fr_add, fr_del, fr_state)
  и `eye_check`. Плюс одна строка в диспетчер после `chat_open`.
Секретов в коде нет. Сервер EYE ставится cloud-init'ом (мозг проекта, задания 52 и 54), сайт — задание 53.
